# CareerAI Frontend

Frontend khởi tạo cho dự án CareerAI bằng ReactJS và Vite.

## Công nghệ
- ReactJS
- Vite
- React Router DOM
- Axios
- Lucide React
- Prettier

## Cài đặt
```bash
npm install
```

Tạo file `.env` dựa trên `.env.example` nếu cần đổi địa chỉ Backend.

## Chạy dự án
```bash
npm run dev
```

Mở địa chỉ hiển thị trong Terminal, mặc định là `http://localhost:5173`.

## Kiểm tra build
```bash
npm run build
```

## Format code
```bash
npm run format
```

## Lưu ý
Các trang trong phiên bản này là khung giao diện để kiểm tra cấu trúc và điều hướng. API đã được chuẩn bị ở thư mục `services`, chưa kết nối Backend thật. Không đặt Gemini API key hoặc mật khẩu database trong Frontend.
